# macOS 远程访问启动包

本包已经开通个人设备身份，包含访问凭据，请勿分享。Apple Silicon 使用 arm64 包，Intel 使用 amd64 包。

在终端进入解压后的目录并运行：

```sh
sh start-macos.sh
```

保持这个终端打开。在 Windows App 或兼容 RDP 客户端中新建电脑，地址填写 `127.0.0.1:13389`，使用家里 Windows 的登录账号和密码。连接的是配置中的 Windows 映射，服务器不公开 RDP 端口。

按 Ctrl+C 停止远程访问。下次重新运行同一命令即可，映射配置会自动同步。其他服务的本地端口以当前访问设备的本地入口配置为准，可运行 `./stargate-remote status --dir "$PWD/state"` 查看。

如果出现本地端口已被占用或进程退出，应先关闭此前启动的同一组件。此包中的两个架构版本使用同一个设备身份，不应在多台电脑上同时运行；另一台设备应单独开通。

当前链路已完成到 Windows 的 RDP 协商测试，macOS 实际桌面登录仍需验证。
