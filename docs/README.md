# 文档入口

建议阅读顺序：

1. `current.md`：当前目标、边界、状态和验收方式。
2. `reference/architecture.md`：当前真实架构和运行策略。
3. `reference/luci-platform.md`：LuCI 管理前端和第一版平台设计。
4. `reference/deployment-notes.md`：OpenWrt 实机部署、验证和排障经验。
5. `roadmap.md`：未来阶段规划。
6. `reference/naming.md`：命名来源和边界。

`reference/` 只记录当前真实系统。未实现的内容应放在 `roadmap.md`，或在文中明确标注 `Status: Not Implemented`。
